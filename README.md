# ⚡ Agy Studio

**Autonomous IDE, Workspace Control Plane & UI for Multi-Agent Orchestration & Adaptive Intelligence**

Rewritten as a modern, high-performance React + TypeScript application with Vite and Tailwind CSS.

## 🌟 Key Features

- 🖥️ **Command Center & 5 Compact Selectors**: Quick workspace switching, studio mode selector (Vibe Coding, Deep Thinking, ATAM Pédagogie, Studio Média, Autonomie), adaptive intelligence badge, multi-agent selector (Antigravity, Hermes, OpenCode, Claude Code, Codex, Qwen), and persistent session management.
- 📝 **Monaco Code Editor & Split Diff**: Integrated code editing with syntax highlighting, language detection, split diff view, and side-by-side comparison.
- 📟 **Interactive Terminal Drawer**: PowerShell xterm.js PTY experience with ANSI styling, instant command execution, and toggle shortcut (`Ctrl+\``).
- 🐙 **Visual Git GUI**: Stage/unstage changes, visual commit log graph (`git log --graph`), AI-powered conventional commit generation, and 1-click push/pull.
- 👻 **Autonomous Ghost Mode**: 4-column kanban task queue (Ready, In Progress, Blocked, Done) with priority levels and Windows 11 toast notification simulation.
- 🗺️ **Project Dependency Graph**: Visual architecture and multi-tier component dependency mapping.
- 🔐 **Secure .env Vault**: Masked credential storage with one-click reveal/hide and copy protection.
- 👁️ **Live Multi-Format Preview & Vision Reflex**: Side-by-side markdown and code preview, 42-page certified formation dossiers inspection, and Playwright headless visual auditing.
- 🧠 **Adaptive Intelligence (3-Tier Memory)**: Episodic, semantic, and procedural memory stores with dynamic confidence metrics.
- ⚡ **Global Shortcuts**: `Ctrl+K` command palette, `Ctrl+B` sidebar toggle, `Ctrl+J` preview toggle, `Ctrl+\`` terminal toggle, `Ctrl+Enter` prompt dispatch.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build production bundle
npm run build
```
